# 개발 로드맵

## 현재 개발된 업무 영역

### 기준 정보
- 공통코드, 직원, 품목, 거래처, 품목단가, 공정

### 거래 업무
- 견적 → 수주 → 출하 → 매출

---

## 추천 개발 순서

### Phase 1 — 기준 정보 보완 (선행 필수)
| 영역 | 이유 |
|------|------|
| **BOM (자재명세서)** | 품목 생산에 필요한 자재와 수량 정의. 생산/자재 소요 계산의 근거 |
| **라우팅 (공정순서)** | 품목별 공정 순서 정의 (기존 공정 마스터 활용) |

### Phase 2 — 자재 관리
| 영역 | 주요 기능 |
|------|-----------|
| **구매발주** | BOM 기반 자재 소요 계산 → 거래처에 발주 |
| **자재입고** | 발주 대비 입고 처리 |
| **재고** | 현재 재고 현황, 입출고 이력 |

### Phase 3 — 생산 관리
| 영역 | 주요 기능 |
|------|-----------|
| **생산계획** | 수주 기반 생산 일정 계획 |
| **작업지시** | 공정별 작업지시서 발행, 담당자 배정 |
| **생산실적** | 작업지시 대비 실제 생산량/불량수량 입력 |

### Phase 4 — 품질 (선택)
| 영역 | 주요 기능 |
|------|-----------|
| **품질검사** | 입고 검사, 공정 검사, 완성품 검사 |

---

## 완성 후 전체 업무 흐름

```
[수주]
  ↓
[생산계획] ← BOM, 라우팅
  ↓
[자재소요계산] → [구매발주] → [자재입고] → [재고]
  ↓
[작업지시] (공정순서대로)
  ↓
[생산실적] → 재고 증가
  ↓
[출하] → [매출]
```
