# BOM 관리 페이지 설계

## 개요

BOM(Bill of Materials, 자재명세서)은 특정 완제품/반제품을 **1개 만들기 위해** 필요한 자재 목록과 수량을 정의한 기준 정보다.

---

## 데이터 구조

```
BOM (헤더)
  ├── 완제품 품목 (Item)       ← 무엇을 만드는가
  ├── BOM 버전                 ← 동일 품목의 변경 이력 관리
  ├── 유효기간 (시작/종료일)   ← 어느 기간에 적용하는가
  └── 상태 (활성/비활성)

BOM Line (자재 목록)
  ├── 자재 품목 (Item)         ← 무슨 자재를 쓰는가
  ├── 소요량                   ← 얼마나 쓰는가
  ├── 단위
  └── 비고
```

---

## 기능 목록

### 1. BOM 목록 조회
- 완제품 코드/명, 버전, 유효기간, 상태로 검색
- 목록: 완제품명, 버전, 자재 수(라인 수), 유효기간, 상태 표시

### 2. BOM 등록/수정
- **헤더 정보**: 완제품 품목 선택, 버전, 유효기간
- **자재 라인 관리**: 자재 품목 선택 + 소요량 입력 (행 추가/삭제)
- 동일 완제품의 동일 버전 중복 등록 방지

### 3. BOM 상세 조회
- 자재 목록 전체 확인
- **버전 이력**: 동일 완제품의 다른 버전 BOM 목록

### 4. BOM 복사
- 기존 BOM을 복사해서 새 버전으로 생성 (자재 목록 그대로 복사 후 수정)
- 버전 업 시 매번 처음부터 입력하는 불편함 제거

### 5. 활성/비활성 처리
- 삭제 대신 비활성 처리로 이력 보존

## 고려 사항

| 항목 | 내용 |
|------|------|
| **버전 관리** | 설계 변경 시 기존 BOM 보존, 새 버전 생성 |
| **유효기간** | 특정 기간에만 적용되는 BOM 지원 |
| **단위 일관성** | 자재 기본 단위와 BOM 소요 단위 일치 여부 |
| **순환 참조 방지** | A 품목 BOM에 A 자재가 포함되는 경우 방지 |
| **다층 BOM** | 자재가 또 다른 BOM을 가질 수 있음 (초기엔 단층 권장) |

---

## 향후 연계

| 연계 영역 | 활용 방식 |
|-----------|-----------|
| **생산계획** | 생산수량 × BOM 소요량 = 자재 소요량 자동 계산 |
| **구매발주** | 재고 부족 자재 자동 발주 |
| **작업지시** | BOM 기반 자재 투입 지시 |

---

## 개발 범위 (단계별)

| 단계 | 범위 |
|------|------|
| **최소** | 완제품 1개 = BOM 1개 (버전 없음), 자재 라인 관리 |
| **권장** | 버전 추가 (변경 이력 관리) |
| **확장** | 유효기간, 다층 BOM |
