# ADR-001: BOM 관리 화면 구조

## 상태
승인됨

## 날짜
2026-03-25

## 맥락
BOM(자재명세서) 관리 기능을 구현할 때, 품목의 하위 BOM을 어떻게 탐색하게 할지 결정이 필요했다.
BOM은 계층 구조(완제품 → 반제품 → 원자재)를 가질 수 있으나, 초기 구현은 단층(직접 투입 자재만 표시)으로 제한한다.
사용자는 투입 자재 중 자체 BOM을 가진 품목의 하위 구조도 조회할 수 있어야 한다.

## 검토한 선택지

- **선택지 A — 페이지 전환 + 화면 재사용**: BOM 목록(화면1)과 BOM 상세(화면2) 2개만 개발. 하위 BOM 조회 시 화면2를 해당 품목 기준으로 재사용.
- **선택지 B — 사이드 패널**: 부모 BOM을 유지한 채 오른쪽에 자식 BOM 패널을 슬라이드로 노출.
- **선택지 C — 인라인 Accordion**: 자재 행을 클릭하면 해당 행 아래로 하위 자재 목록이 인라인 확장.

## 결정

**선택지 A (페이지 전환 + 화면 재사용)** 를 채택한다.

- 화면 2개(목록, 상세)만으로 구현 범위를 최소화
- 화면2는 품목 파라미터만 바꾸면 어떤 품목의 BOM도 동일하게 표시 가능 → 재사용성 높음
- URL/히스토리 스택으로 이동 경로를 관리하여 향후 브레드크럼 확장 용이
- 초기 단층 BOM 수준에서 가장 단순하고 유지보수하기 쉬운 구조

## 결과

### 긍정적
- 구현 복잡도 최소화
- 화면2 단일 컴포넌트로 모든 품목의 BOM 상세 처리 가능
- 브레드크럼, 사이드 패널 등 향후 확장 경로가 열려 있음

### 부정적 / 트레이드오프
- 동시에 두 BOM을 나란히 비교하는 기능 불가 (사이드 패널 방식 대비)
- 드릴다운 깊이가 깊어질 경우 브레드크럼 없이는 현재 위치 파악이 불편할 수 있음 → URL 경로 관리 필수
